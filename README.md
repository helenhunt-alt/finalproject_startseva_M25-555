# Final Project - Валютный кошелек

Проект представляет собой консольное приложение, имитирующее работу валютного кошелька.  
Реализован как полноценный Python-пакет.

## Запуск

Установка зависимостей и запуск проекта:

```bash
make install
make project
```

## Команды
- `make install` — установка зависимостей и пакета
- `make project` — запуск приложения
- `make build` — сборка пакета
- `make publish` — проверка публикации пакета (--dry-run)
- `make package-install` — установка пакета из wheel
- ` poetry env activatemake lint` — проверка кода линтером Ruff
